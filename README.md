# cherri

Static site files for cherri. The app and all of its bundled scripts, styles, fonts, and images are in `b/`.

## Open the site

After this repository is public, use the jsDelivr URL:

<https://cdn.jsdelivr.net/gh/BombedByXander/svg@main/b/index.html>

The repository root redirects to the app at `b/index.html`. The app loads its bundled assets from paths relative to that directory.

jsDelivr hosts the static files. Features that use external services still need those services to be available in the browser.
